GlennBot Internal API & n8n Automation Hub REST API v1

Generate your own GlennBot API Keys (gb_live_...) & automate Posts, Messages, Emails, Comments, and Contacts from n8n

Base API URL for n8n HTTP Request Node (Auto-Detected)
/api/v1
Active Internal API Keys (gb_live_...)
How to use in n8n: Add an HTTP Request node in n8n, set Authentication to Header Auth with Name X-API-Key and Value set to your generated gb_live_... key (or pass ?api_key=gb_live_... in the URL).
POST /api/v1/posts/publish Facebook • Instagram • TikTok • YouTube

Publish immediately or schedule a text, image, or video post from n8n.

{
  "platforms": ["facebook", "instagram"],
  "post_type": "image",
  "caption": "Automated post from n8n!",
  "image_urls": ["https://example.com/photo.jpg"],
  "publish_now": true
}
POST /api/v1/emails/send Gmail • Microsoft • IMAP

Send a new email or reply to an existing email thread using your connected email account.

{
  "to": "client@example.com",
  "subject": "Your Inquiry Update",
  "body": "Hello! Here are the details you requested."
}
POST /api/v1/messages/send FB • IG • WhatsApp • Telegram

Send a direct message reply to any active conversation across connected chat channels.

{
  "account_id": "YOUR_ACCOUNT_ID",
  "conversation_id": "CONVERSATION_ID",
  "message": "Hi! Thanks for messaging us."
}
POST /api/v1/contacts Auto-Deduplicates Phone & Email

Add or update a lead in GlennBot CRM (automatically merges duplicate numbers/emails).

{
  "first_name": "Juan",
  "last_name": "Dela Cruz",
  "contact_number": "09171234567",
  "email_address": "juan@example.com",
  "platform": "whatsapp",
  "category": "Hot Lead"
}
POST /api/v1/comments/reply Public Reply or Private DM

Reply to a post comment or set send_dm: true to send a private DM to the commenter.

{
  "record_id": "POST_RECORD_ID",
  "comment_id": "COMMENT_ID",
  "message": "Sent you the details!",
  "send_dm": false
}
